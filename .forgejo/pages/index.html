m5stack-core

Board support crate for the M5Stack Fire27 (ESP32) and CoreS3 (ESP32-S3). Exactly one board feature is enabled per build and each selects different hardware, so the API is documented once per board:

  • Fire27 — ESP32 (fire27)
  • CoreS3 — ESP32-S3 (cores3)

Both trees are built from the tip of master with every optional feature enabled, so they can be ahead of the released crate. Links to items from other crates do not resolve — only this crate is documented here.

This site exists because docs.rs cannot build the crate: its stock toolchain has no Xtensa backend, which is the only architecture the two supported boards use. Source · crates.io
