Reset gating (important): the AW9523B RSTN is wired to AXP_PG (AXP2101 power-good) and has an internal ~100 kΩ pull-low — so the expander is held in reset until the AXP asserts power-good. It in turn drives LCD_RST / TOUCH_RST, so panel + touch bring-up all chain off it. See power_display_reset for the cold-boot readiness handling.

Structs§

The CoreS3’s peripherals, split into board-fact groups. See Board::split.

Zero-sized display-DC “pin” that drives GPIO35 via direct register writes.
M5Bus
External M5-Bus pins the BSP does not claim for on-board functions. What hangs off them (1-Wire sensors, RPM pickups, …) is application wiring. Not exhaustive — extend as needed.

Functions§

apply_pending_dc
Drive GPIO35 to the DC level recorded by Gpio35Dc.
gpio35_disable_output
Disable the GPIO35 output driver so the pad returns to high-impedance input (SPI2 MISO). Must be called before any SD-card SPI operation — both at bring-up (after display init; super::spi2 does it) and per-op at runtime (pass this as the block-device handler’s pre-op hook).
power_display_reset
Power + display bring-up over the shared I2C bus: AW9523B IO-expander (LCD_RST + touch reset) then AXP2101 PMIC backlight (DLDO1 @ 3.3 V).
