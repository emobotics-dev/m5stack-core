pub fn init(spec: &'static str)
Expand description

Register the console as the global log backend. Call once, early. The ring is statically initialised, so producers can write immediately — pre-drain_task writes simply accumulate in the ring and are flushed once the drain runs. spec is an env_logger-style filter (info,sdspi=debug), typically the app’s ESP_LOG read at the APP’s compile time — the console previously hardcoded Info here, which silently discarded every module=debug directive from the day esp-println (whose logger parsed ESP_LOG) was dropped.
